# social-app

## Setup

1. Set up your [development environment](https://docs.appdevncsu.org/react-native/01_dev_env/) with VS Code, Node.js, and Expo Go.
2. Clone this repository in a folder of your choice
3. Inside the `react` folder, run `npm install` to install the app's dependencies
4. Inside the `react` folder, run `npm run start` to run the app
